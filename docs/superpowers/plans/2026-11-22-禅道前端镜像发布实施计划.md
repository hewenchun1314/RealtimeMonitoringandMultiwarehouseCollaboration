# 禅道前端镜像发布实施计划

**目标** 为纯前端和前后端工单增加合回后发布至 Harbor 的受控阶段。

**架构** SQLite 账本安排阶段并校验发布回执。Windows 启动器驱动独立 Python 发布执行器，执行器调用已有 Node 打包工具和 Docker。

**技术栈** Python、SQLite、Windows Job Object、Git、Node.js、Docker。
