# 海能发地质工程一体化前端 E2E 操作手册

测试 Agent 从这里查找平台入口、导航路径和已知的页面操作。每张工单的验收范围以需求验收条件和本单计划为准。新增业务场景时，可在需求材料中沿用文末的用例格式，补齐操作和测试数据。

## 登录和进入项目

1. 从工单配置快照读取 `e2e`。基座未启动时，按 `e2e.start_command` 从本单对应的基座工作区启动。基座地址由 `e2e.ready_url` 或启动输出确认。下文示例使用本机常用地址 `http://localhost:5000`。
2. 无人值守运行使用 AgentLimb 和已配对的 Chrome 配置。复用平台会话或 Chrome 为配置账号填充的登录信息，进入 `/aggregation-platform/sso/home-page/platform`。需要人工认证时记录「等待登录」。
3. 在平台首页确认本用例要求的工区，再进入「测井解释」。当前默认工区是「海能发陆上示范区工区」。有指定测试井的用例以该井所属工区为准。
4. 进入业务页后，核对浏览器加载的各改动应用属于本单待验提交。可记录子应用资源 URL 和响应哈希，并与待验提交的构建产物比对。合回前测试候选提交，补验已合回版本时记录实际合回提交。

启动、超时和证据归档见 [E2E 阶段指引](../.agents/skills/zentao-autodelivery/references/e2e.md)。当前入口和默认工区见 [项目配置](../.agents/zentao-project.json)。

## 交汇图与曲线校验

| 页面 | 菜单路径 | 本地入口 |
| --- | --- | --- |
| 交汇图 | 测井解释 → 数据预处理 → 交汇图 | `/aggregation-platform/shell-hub/data-preprocessing?preprocessingTab=crossplot` |
| 曲线校验 | 测井解释 → 数据预处理 → 曲线校验 | `/aggregation-platform/shell-hub/data-preprocessing?preprocessingTab=curve-validation` |

以下用例来自 #36（REQ-033）。交汇图为改动页面，曲线校验为同主题下的样式参照。

| 场景 | 操作 | 预期结果 |
| --- | --- | --- |
| 设置弹窗和主题（F1） | 打开交汇图。分别点「交汇图设置」和「更多选项」。用 Tab 移动焦点，用 Esc 关闭，再重开并点关闭按钮。切到「曲线校验」后再切回。明暗主题分别复查。 | 弹窗、遮罩、标题、关闭按钮和底部操作区可见。Esc 关闭后焦点回到打开按钮。两页签可正常打开，记录同主题的对照截图。 |
| 工具栏和异常点清单（F2） | 从井树选指定测试井，按用例选择 X/Y 曲线。等异常点清单加载后，依次检查套索、多选、清空、确认、取消、定位、行处理和撤销。切到曲线校验，用同一测试井查看指定数据集和详情。 | 清单有用例指定的记录。按钮状态随选择和草稿变化，定位命中预期行，处理与撤销结果符合用例。两页签同用途按钮的显示与计划中的对照一致。 |
| 处理、覆盖和回读（F1） | 打开指定的可恢复测试草稿。在异常点清单选择指定行，打开处理弹窗，完成用例规定的修改。打开保存弹窗，确认覆盖指定测试目标。刷新并重新打开正式结果。 | 保存响应成功。重新打开后能读到预期曲线值或正式结果，保存和回读请求与用例预期一致。 |
| 未保存时切换页签（F1） | 在指定测试记录中制造未保存修改，点击「曲线校验」。从相同初始状态分别复验取消离开、放弃和「保存后继续」。 | 取消时留在交汇图且草稿保留。放弃后切到目标页签。保存后继续应在保存成功后切换，取消保存或保存失败时留在当前页。 |

已在实际基座确认设置入口、键盘操作和页签切换。处理、覆盖及部分清单行为有模拟数据证据，真实写入和回读需要下表中的测试记录。

### #36 待补的测试数据

| 需要指定 | 填写内容 |
| --- | --- |
| 工区、井和曲线 | 工区及井的稳定 ID，交汇图 X/Y 曲线，以及曲线校验使用的数据集 |
| 异常点和初始状态 | 可定位的异常点记录，处理前数值，以及预期修改值或结果 |
| 草稿和覆盖目标 | 可写的测试草稿、允许覆盖的目标，以及测试后如何恢复初始状态 |

进入写入场景前，在页面确认工区、井和记录与用例一致。缺少记录或权限时，保留已完成场景的证据，写明待验证的操作和缺少的输入。可用已有夹具验证对应界面和请求行为，并记录夹具所覆盖的范围。

## 新工单的用例格式

每条用例写明以下内容，可追加在需求材料中供测试 Agent 读取。

| 字段 | 填写内容 |
| --- | --- |
| 对应验收项 | 需求 AC 编号、任务编号、改动应用 |
| 项目入口 | 菜单路径、相对 URL、进入后用于确认到达的页面元素 |
| 测试数据 | 所需账号角色或凭据引用、工区、案例或井、具体记录、初始状态，涉及写入时附恢复方式 |
| 操作 | 按顺序写出要选的值、要点的按钮，以及每步需要等待的页面状态 |
| 预期和证据 | 可观察结果，以及需要留存的截图、脱敏请求或刷新回读结果 |
