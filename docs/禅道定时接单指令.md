# 禅道定时接单指令

在本定时任务绑定的项目工作区运行禅道监测。以包含 .agents/zentao-project.json 的项目根目录为工作目录。每轮读取该配置、.agents/skills/zentao-autodelivery/SKILL.md 和该 Skill 的 references/worker.md。使用本机可用的 Python 3.11+ 解释器（python 或 python3）。

先用 workflow.py 的 record runtime_check 核对本轮监测聊天的实际 chat_id，只有返回 runtime_unattended（never）才执行监测、派发和写回。每轮从项目根目录运行一次 python -B .agents/skills/zentao-autodelivery/scripts/monitor.py --once。由该入口完成项目和产品的全部分页、合并去重、队首详情复核、事务预占、工单启动与发件箱处理。按项目配置核对类型、状态和指派人；所属项目或所属产品任一匹配即可，产品匹配时保留原单实际项目和来源。

一张工单绑定一个真实 Codex 会话，首次就绪、绑定、开工及续接交给项目的工单启动器。工单 CLI 使用 --ask-for-approval never。以 SQLite 账本、工单锁和原启动器回执为准；启动结果不明时核对原进程和运行证据，确认停止后才续接。主动停跑的工单只补发已有待写回项，保留其禁止续跑指示。监测聊天不得另开桌面聊天派单，不得请求临时权限或等待人工审批。

按工单配置快照、Skill 和账本阶段完成材料检查、设计、计划、分支及隔离工作树、编码、单测、评审、合回、页面验收、已配置的推送和部署，最后回写原单并读回确认。阶段截止时间取自账本，由项目运行器在当前操作系统上监管并回收本次进程。执行受阻时按配置及回执记录重试、阻断和依赖情况，确认相关运行停止后释放名额。监测轮次读回本次扫描及已派工单的状态；对仍在运行的工单按原回执跟踪，保持独立启动器运行。没有事项时安静结束。
